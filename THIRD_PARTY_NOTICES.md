# Third-party source and algorithms

## Vendored Sygaldry code

`vendor/tnwf-paper` contains selected files copied from
[sygaldry-tech/tnwf-paper](https://github.com/sygaldry-tech/tnwf-paper), commit
`11358d3dca52193f93f037046229797296a2063e`.

Copyright (c) 2026 Sygaldry Technologies, Inc.

That source is distributed under the MIT License. The full license is
preserved in `vendor/tnwf-paper/LICENSE`. Its own third-party dependency
notices are retained under `vendor/tnwf-paper/licenses/`. Our project license
does not replace those notices. The upstream code is unmodified.

The legacy `gmm_*` checkpoints in `data/checkpoints` were generated by this project
using the upstream public architecture and training objective. They are not
copies of the paper's unpublished or archived model checkpoints. The upstream
public trainer omits an unpublished regularizer, as documented in
`docs/training_and_data.md`.
The compiler benchmark uses slices of the upstream example checkpoint
`vendor/tnwf-paper/examples/checkpoints/mps_v_gmm_d8.pt` as distributed with the
pinned MIT-licensed repository. See [checkpoint provenance](docs/v03_literature.md).

## Reused algorithms and research attribution

The following are established algorithms reused or implemented by this
benchmark; no priority claim is made for them:

| Component | Reference |
|---|---|
| Wavefunction-flow Hamiltonian and commutator evolution | [Layden et al., arXiv:2510.08462](https://arxiv.org/abs/2510.08462) |
| MPS-V model, training, and proposed reversible TT contraction route | [Kodama et al., arXiv:2608.21700](https://arxiv.org/abs/2608.21700) |
| QROM phase kickback and trained quantum encoders for wavefunction flows | [Che and af Klinteberg, arXiv:2610.11537](https://arxiv.org/abs/2610.11537) |
| QROM and unary selection | [Babbush et al., arXiv:1805.03662](https://arxiv.org/abs/1805.03662) |
| SelectSwap space/time tradeoff | [Low, Kliuchnikov and Schaeffer, arXiv:1812.00954](https://arxiv.org/abs/1812.00954) |
| Walsh diagonal phase synthesis | [Welch et al., arXiv:1306.3991](https://arxiv.org/abs/1306.3991) |
| Diagonal circuit synthesis | [Bullock and Markov, QIC 4 (2004)](https://doi.org/10.26421/QIC4.1-3) |
| Ripple-carry addition | [Cuccaro et al., arXiv:quant-ph/0410184](https://arxiv.org/abs/quant-ph/0410184) |
| Reversible quantum arithmetic | [Vedral, Barenco and Ekert, arXiv:quant-ph/9511018](https://arxiv.org/abs/quant-ph/9511018) |
| Commutator product formulas | [Childs and Wiebe, arXiv:1211.4945](https://arxiv.org/abs/1211.4945) |
| Tensor-train representation | [Oseledets, SIAM J. Sci. Comput. 33 (2011)](https://doi.org/10.1137/090752286) |
| Rotation-synthesis resource model | [Ross and Selinger, arXiv:1403.2975](https://arxiv.org/abs/1403.2975) |

The SelectSwap implementation uses clean banks and exact coherent Toffoli
gates. It does not claim the gate constants of measurement-assisted or
dirty-ancilla constructions. Rotation-synthesis counts are model-based
estimates; no synthesis implementation is copied from Ross and Selinger.

## Runtime dependencies

Runtime dependencies are installed separately using the pinned environment;
their package source and binary wheels are not redistributed in the project
archive. Principal dependencies are NumPy (BSD), SciPy (BSD, with its own
bundled-library notices), PyTorch (BSD-style), Qiskit (Apache-2.0), Matplotlib
(its PSF-based license), scikit-learn (BSD), and pytest (MIT). Their complete
license terms are supplied by their respective distributions. Retained
upstream dependency notices are informative and do not substitute for the
licenses of the versions installed for this benchmark.

The rest of the new FlowOracleBench source is licensed under the root MIT
license, copyright 2026 FlowOracleBench contributors.

## Flow matching and inference

The smooth scalar model uses conditional flow matching from
[Lipman et al.](https://arxiv.org/abs/2210.02747). The inference benchmark uses
maximum likelihood amplitude estimation from
[Suzuki et al.](https://arxiv.org/abs/1904.10246). The smooth model checkpoints
come from this project.
